# 21-Day Operator Curriculum

One lesson per day, ≤45 minutes each, zero platform knowledge assumed. /reflect checks the box when the operator reports the lesson done; /daily advances the pointer to the next unchecked day and puts the current lesson in Today's Top 3.

**Current day: 1**

## Week 1 — From zero to first listing (fixed)

- [ ] **Day 1 — Etsy buyer account + competitor immersion (40 min).** Go to etsy.com → "Sign in" (top right) → "Register" → create a personal buyer account with your email. Then search "Arabic name sign wood", "Eid gift personalized", "Islamic wall art". Open 10 shops selling these; for each note: price band, review count, photo style, and any Arabic script errors you spot (log each observation with /audit — this feeds Gate A's ≥20-audit requirement).
- [ ] **Day 2 — Seller account + shop name shortlist (45 min).** On etsy.com, scroll to the footer → "Sell on Etsy" → "Get started". Follow the prompts to open a seller account (shop preferences: language English, country, currency USD). Stop at the "Name your shop" step: draft a shortlist of 5 names (available, pronounceable, no trademark issues, works in English, hints at Arabic/wood craft). Do not pay for anything. Pick one tomorrow after sleeping on it.
- [ ] **Day 3 — Printify account + Etsy link + auto-fulfillment (45 min).** Go to printify.com → "Sign up" (free plan). In Printify: "Manage My Stores" → "Add new store" → choose Etsy → "Connect" → log into Etsy when prompted → approve the app's permissions. Then in Printify: Settings → Orders → confirm order approval is set so paid Etsy orders go to production automatically (auto-fulfillment: a paid order flows to production and ships without you touching it). Browse Printify's catalog for wood/engraved products and shortlist 5 that fit the Entry tier.
- [ ] **Day 4 — First sample order to yourself (30 min).** In Printify, open one shortlisted product → "Start designing" → place a simple test design (your name in Arabic, verified with /design-spec) → order a **sample** to your own address (Printify: product page → "Order sample"). Log the cost with /log (category: samples). This is Gate A evidence: 3 samples must pass QC.
- [ ] **Day 5 — Draft 3 listings with /listing (45 min).** Run /listing three times: one Entry (engraved name sign), one Entry (Eid board — names/geometry only, per adab rule), one Mid (layered Ayat al-Kursi wall panel). Save the drafts; do not publish yet.
- [ ] **Day 6 — Photograph samples (45 min).** Using knowledge/phone-photography.md (and its researched kit if bought — log any spend with /log): shoot the sample from Day 4 — hero on clean background, engraving detail in raking light, scale shot, one lifestyle shot. Pick the best 5.
- [ ] **Day 7 — Publish the first listing (40 min).** In Etsy: Shop Manager → Listings → "Add a listing". Paste the Day-5 draft: photos → title → category → price → description (including the adab policy line) → 13 tags → link the Printify product (in Printify, publish the product to your Etsy store and it appears as a draft listing to finish). Click "Publish" ($0.20 listing fee — log it with /log). Log the listing in data/listings.csv via /log.

## Weeks 2–3 — Traffic, conversion, retention

- [ ] **Day 8 — Etsy SEO fundamentals (40 min).** Read knowledge/listing-seo.md; rewrite Day-7 listing's title and 13 tags against it; note before/after in data/experiments.csv.
- [ ] **Day 9 — Publish listings 2 and 3 (45 min).** Repeat the Day-7 flow for the two remaining drafts. Log fees and listings.
- [ ] **Day 10 — Competitor audit sprint (45 min).** /audit 5 more competitor listings toward the ≥20 Gate A target; update the price map in knowledge/pricing-psychology.md observations.
- [ ] **Day 11 — Etsy Ads primer + $150 promoted-listings test plan (40 min).** Learn Etsy Ads mechanics (Shop Manager → Marketing → Etsy Ads); write the test as a hypothesis row in data/experiments.csv: budget $150 total, daily cap, target listings, success metric (cost per click, cost per order). **Do not turn ads on until the operator explicitly decides** — this is a budget decision.
- [ ] **Day 12 — Packaging insert design (45 min).** Design a thank-you insert: care instructions, the adab statement, a discount code for next order, and an email-capture invitation (e.g. "join the list for Eid pre-orders"). Draft with /design-spec conventions; produce print-ready text.
- [ ] **Day 13 — Email capture setup plan (40 min).** Choose the free-tier email tool; map the capture path (insert QR → landing page → list). Human-only signup; log any cost with /log first if a paid tier is ever proposed (it needs an explicit decision).
- [ ] **Day 14 — Week-2 review + /gate dry run (30 min).** Run /review, then /gate to see Gate A pace. Fix the biggest gap next week.
- [ ] **Day 15 — Content cadence: process video 1 (45 min).** Film one 15–30s process/personalization clip (design → engrave preview → pack). Post to the listing video slot first; social later. Note engagement window: 10pm–2am peaks (docs/market-facts.md).
- [ ] **Day 16 — Review-request flow (30 min).** Write the post-delivery message sequence (Etsy allows buyer messages — no spam, one ask); add the review ask to the packaging insert; log the template in data/experiments.csv as a hypothesis.
- [ ] **Day 17 — Listings 4–6 drafted (45 min).** /listing for three more SKUs (birth board — names/dates only, monogram, Eid countdown wall piece). Verify each with /design-spec.
- [ ] **Day 18 — Photography round 2 (45 min).** Shoot new samples/mockups; A/B the first image on the oldest listing; log the swap in data/experiments.csv.
- [ ] **Day 19 — Holiday cutoffs + calendar (40 min).** From knowledge/eid-ramadan-campaign.md research: put Ramadan/Eid 2027 cutoffs, Gate B (31 Oct) and Gate C (31 Dec) on your calendar; add cutoff copy to listings when in season.
- [ ] **Day 20 — Promoted-listings decision (30 min).** With ≥2 weeks of listing data, decide the $150 ads test: run /brief, check budget remaining, then the operator turns ads on or defers. Log the decision in data/experiments.csv.
- [ ] **Day 21 — Full review + next-30-days plan (45 min).** Run /review and /gate. Write the next 30 days' focus into state/backlog.md seeds. Curriculum complete — /daily now drives cadence alone.
