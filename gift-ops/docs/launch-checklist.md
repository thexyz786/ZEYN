# Launch Checklist

Ordered, human-only tasks. Every item is done by the operator with their own hands and accounts — the system drafts and instructs, never executes. Mirrors curriculum days 1–7, then the two post-launch levers. Check items off here as done; log every cost with /log.

1. [ ] **Create Etsy buyer account** and browse 10 competitor shops; log observations with /audit. *(curriculum Day 1)*
2. [ ] **Open Etsy seller account**; shortlist 5 shop names; choose one. *(Day 2)*
3. [ ] **Create Printify account (free plan)**, connect it to the Etsy shop, and **enable auto-fulfillment** (auto order approval). *(Day 3)*
4. [ ] **Order first POD sample to yourself**; log the expense (category: samples); QC it against docs/adab-guardrails.md when it arrives. *(Day 4)*
5. [ ] **Draft 3 listings with /listing** (2 Entry, 1 Mid); verify scripts with /design-spec. *(Day 5)*
6. [ ] **Photograph the sample** per knowledge/phone-photography.md; pick the best 5 shots. *(Day 6)*
7. [ ] **Publish the first listing** on Etsy (paste draft, link Printify product, pay the $0.20 listing fee — log it); append the listing via /log. *(Day 7)*
8. [ ] **$150 promoted-listings test** — only after ≥2 weeks of listing data and an explicit budget decision: write the hypothesis in data/experiments.csv, set the daily cap in Etsy Ads, log spend weekly, judge by cost per order at /review. *(curriculum Days 11 & 20)*
9. [ ] **Email capture live from order one** — packaging insert with QR → signup page on a free-tier tool; first-party list is the hedge against Etsy dependence. *(Days 12–13)*

Standing rules: nothing on this list is ever performed by the system; no step is marked done unless the operator actually did it; every dollar is in data/expenses.csv the day it moves.
